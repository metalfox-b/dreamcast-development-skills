# Asset originality and sources

Create original designs and assets that match the user's brief. Use source material only when its license or the user's rights permit the intended use. Study existing games for techniques and published technical information; do not copy protected assets unless the user has the necessary rights and requests their use.

Record the origin and license of each texture so the project can verify its assets before release. A simple `textures/SOURCES.md` can contain:

| File | Source | License or permission | Notes |
|---|---|---|---|
| example_face.pal8.png | Original painting | Project-owned | Palette and locked colors |
| example_stone.vq565.png | Licensed photo | Record the license and link | Edited and quantized |

Follow the project's own rules for source files, generated files, and distribution. Honor the user's requirements for human-made or generated art.
